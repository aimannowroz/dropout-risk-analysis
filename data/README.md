# Data

## Survey responses (not included)

The primary dataset is 228 responses to an anonymous survey of students at GIKI, LUMS, NUST and AKU. Respondents took part for research purposes, so the raw responses are not published here.

`sample_survey.xlsx` is **synthetic**. It has the same 19 columns and answer formats as the real survey, filled with random values, so the notebook runs end to end. Results from it are meaningless; the real results are described in the main README.

## International validation dataset

The cross-dataset section uses *Predict Students' Dropout and Academic Success* (Realinho et al., UCI Machine Learning Repository, also on Kaggle; CC BY 4.0). Download the CSV and save it here as `kaggle_dropout.csv`.
